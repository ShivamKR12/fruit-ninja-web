# Fruit Ninja (Web Edition)

A fruit-slicing arcade game built with Python and Pygame-CE. Slice as many flying fruits as possible while dodging bombs.

Playable locally and in modern web browsers via WebAssembly ([Pygbag](https://pygame-web.github.io/)).

## How to Run Locally

### Prerequisites
- Python 3.10+
- `pip install pygame-ce pygbag`

### Play Locally
```bash
python main.py
```

### Run in Browser Locally
```bash
python -m pygbag main.py
```
Open `http://localhost:8000` in your web browser.

## Controls
- **Mouse Drag / Touch**: Slice flying fruits
- Avoid slicing bombs
